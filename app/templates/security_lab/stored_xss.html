MITIGATION

Encode for the output context

Mitigated mode applies server-side HTML escaping before the value reaches this HTML text node. Characters such as less-than and greater-than become text entities, so the browser does not build a script element. Legitimate review text remains readable, and ordinary markup is treated as text.

This page-specific lab CSP permits inline script only while the approved value is rendered in effectively vulnerable mode. CSP is defense in depth; output encoding is the primary mitigation. Normal marketplace review pages retain their strict default CSP and automatic template escaping.

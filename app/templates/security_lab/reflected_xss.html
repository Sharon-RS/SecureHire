Reflected XSS

Reflected Cross-Site Scripting occurs when request input is returned in the same response as executable markup instead of being encoded as text.

Attack flow: a user submits input, the server inserts it into the response, and the browser interprets unsafe markup. Unlike Stored XSS, this input is not saved for later viewers; it is reflected immediately in this response.

MITIGATION

Encode for the HTML output context

Mitigated mode HTML-escapes the submitted value before inserting it into this text node. Characters that form tags become text, so the browser does not create or execute a script element. The renderers are separate server-side functions; no blacklist or client-side sanitizer provides the mitigation.

CSP is defense in depth, not the fix. Only the response containing the exact approved payload gets an inline-script exception, and only while vulnerable mode is effective through the server-side gate. Other pages keep the default restrictive CSP.

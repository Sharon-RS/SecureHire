Clickjacking (UI Redressing)

Clickjacking occurs when an attacker uses transparent or disguised <iframe> layers to trick an authenticated user into clicking an unintended button or control on a vulnerable target site, hijacking the user's authenticated session.

Effective mode: {{ state.effective_mode|upper }} Protection: {{ state.protection_status }}

ATTACK FLOW

How UI redressing hijacks authenticated user clicks

  1. An attacker finds a sensitive, 1-click state-changing action on an application that lacks anti-framing headers.
  2. The attacker crafts a deceptive decoy webpage (e.g. "You won a $100 Freelancer Platform Bonus! Click here to claim").
  3. The attacker embeds the vulnerable target action inside an <iframe> positioned directly underneath the decoy lure with opacity: 0.0001 (virtually invisible).
  4. The unsuspecting user clicks the decoy button, but their mouse event strikes the invisible underlying target action, executing it on their behalf.

MITIGATION

Modern defense against UI redressing

  • 1. Content-Security-Policy (CSP) frame-ancestors: The modern, W3C-recommended standard. Setting Content-Security-Policy: frame-ancestors 'none'; instructs the browser to refuse to render the page inside any frame or iframe, regardless of origin.
  • 2. X-Frame-Options: DENY (Defense in Depth): Legacy HTTP response header for older browsers that lack CSP Level 2 support. Setting DENY forbids all framing. Setting SAMEORIGIN allows framing only by pages on the exact same origin.
  • 3. Why "Frame-Busting" Scripts Are Inadequate: Legacy JavaScript snippets (such as if (top != self) top.location = self.location;) can be neutralized by attackers using HTML5 <iframe sandbox="allow-forms allow-scripts"> without allow-top-navigation, or by registering an onbeforeunload handler. Declarative HTTP headers are mandatory.
  • 4. SameSite Cookie Attributes: Configuring session cookies with SameSite=Lax or SameSite=Strict ensures that ambient session credentials are not attached to cross-site state-changing POST requests triggered inside framed contexts.
